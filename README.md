# 光阑换位操作可导出性审计

工程师在光学载荷检修时确认：一组**允许的光阑换位操作**能否实际导出**目标接线次序**，
避免把看似相同的端口排列误当成可执行规程。页面提供两种复核模式（可随时切换）：

- **普通可导出复核**：录入 **2–12 个稳定端口**、**至多 8 个具名置换操作**及一个**目标置换**；
  页面返回 **“可导出”** 与可逐步回放的操作因子链；或返回**首个无法继续归约的端口层**
  及其轨道证据（基点像不在该层轨道内）。
- **执行奇偶复核**：在普通复核基础上，为每个已定义操作指定本次规程中出现
  **奇数次还是偶数次**（逆操作仍计入该操作一次）。目标可导出时，系统在恒等关系的
  **GF(2) 奇偶空间**中求解，返回满足整组奇偶要求的**规范因子链**；若仅奇偶要求不可满足，
  则展示目标代表词的奇偶向量、所需差额与独立恒等关系基。

核心计算在 **Web Worker** 中按**端口标识排序**建立**确定性 Schreier–Sims 稳定子链**；
成员结论由各层**横截代表逐层剥离复算**，因子词再逐操作乘回独立校验；
奇偶复核只在该链上做 **GF(2) 高斯消元与词回构**——
不枚举全部群元素、不穷举操作串、不使用随机搜索、不以有限深度回放代替。

## 置换记法

| 形式 | 示例 | 说明 |
| --- | --- | --- |
| 循环记号 | `(A B C)(D E)` | A→B→C→A，D↔E；未出现的端口为固定点 |
| 显式映射 | `A->B, B->C, C->A` | 接受 `->` `→` `=>` `:`；必须覆盖全部端口 |

每个操作必须是端口集合上的**双射**。重复操作名、缺失端口、非双射映射、非法目标等
**全部错误一次性返回**，且任何输入改动都**立即撤销旧结论**。

## verify 服务（一次性，按状态码报告）

```bash
docker compose build
docker compose run --rm verify
```

`verify` 依赖 `web` 服务健康检查通过后启动，依次执行：

1. **代码测试**（`node --test`，42 项）——含一份可导出规程、一份不可导出目标、
   与全枚举 BFS 对 n≤5 全部目标的成员结论对照、A5=60 阶、S12=12! 阶、
   全量校验错误聚合、Worker 协议往返；以及执行奇偶复核专项：
   在 (置换, 奇偶掩码) 扩展状态空间上对 n≤5、全部目标×全部奇偶要求做穷尽对照
   （756 组合）、可行规范链乘回与逐操作计数复核、仅奇偶不可满足时的
   代表向量/差额/独立关系基诊断、n=12 规模下 GF(2) 求解性能；
2. **构建检查**——全部 JS `node --check`、静态资源引用完整性、核心 API 导出；
3. **HTTP 冒烟**——`/healthz`、审计页、静态资源、路径穿越拒绝、404。

全部通过退出码 0，任一失败非零退出，随后容器退出（不长期驻留）。

## 算法说明（确定性 Schreier–Sims）

- 基点顺序固定为端口标识排序后的 `[0,1,…,n-1]`；
- 每层 `i` 维护强生成元集 `S[i]`、基点轨道及**横截代表**（含对应的生成元词）；
- 初始生成元按操作名排序后逐条剥离；用 Schreier 生成元
  `β(x)·g·β(g(x))⁻¹` 反复闭合直至无新点、无新残差（确定性顺序、有限终止）；
- 目标剥离：逐层以横截代表之逆消去基点像；像点不在轨道内即给出
  **首个阻塞端口层 + 轨道证据**；全部基点消去为恒等则成员成立；
- 因子词 `target = t_{n-1}·…·t_0` 按可执行顺序展开，供逐步回放，并独立乘回复核。

## 执行奇偶复核（GF(2) 奇偶空间）

- 记 `g_1,…,g_m` 为已定义操作，词中第 k 个操作（含其逆元记号）每出现一次，
  奇偶向量第 k 位翻转一次；所求规程的奇偶向量必须等于逐操作给定的整组要求 `d`。
- 目标剥离所得代表因子链 `w0`（`φ(w0)=target`）的奇偶向量为 `p0`，
  则可行 ⇔ **差额 `d+p0`（GF(2)）落在恒等关系词的奇偶空间内**。
- 恒等关系空间直接在**已闭包完备的 Schreier–Sims 链**上构造：每层每个
  Schreier 生成元 `β(x)·g·β(g(x))⁻¹` 在完备链上必能被更深层横截代表剥离为恒等，
  其 Schreier 词拼上剥离用代表逆词即一条补偶恒等词；收集全部此类词的奇偶向量，
  做 **GF(2) 高斯消元**得独立关系基（Reidemeister–Schreier 重写的模 2 投影保证其张成整个空间）。
- 差额在基上的系数解确定后，把相应关系词按确定性顺序拼接为**补偶恒等词**，
  规范因子链 `w = w0·（补偶恒等词）`；引擎独立校验补偶词乘回为恒等、
  整链乘回为目标且奇偶向量逐位等于要求，再交给页面逐步回放——
  回放每步带逐操作累计次数与当前奇偶，可与整组要求逐列核对。
- 仅奇偶不可满足时返回：目标代表词奇偶向量 `p0`、差额 `d+p0`、
  主元列严格递增的独立关系基；目标本身不可导出时仍只给**首个阻塞层**，不进入奇偶判定。

## 并发与代次隔离

每次提交递增 `requestId`（代次）。计算未结束时改写规程（端口、操作、目标、
**审计模式或任一奇偶选择**）都会使代次前移并撤销旧结论；
旧 Worker 回包代次不匹配即被丢弃，**不会覆盖新输入或新结论**。
