# 光阑换位操作可导出性审计

工程师在光学载荷检修时确认：一组**允许的光阑换位操作**能否实际导出**目标接线次序**，
避免把看似相同的端口排列误当成可执行规程。

- 录入 **2–12 个稳定端口**、**至多 8 个具名置换操作**及一个**目标置换**；
- 页面返回 **“可导出”** 与可逐步回放的操作因子链；
- 或返回**首个无法继续归约的端口层**及其轨道证据（基点像不在该层轨道内）。

页面顶部可切换到**整组奇偶复核**模式：为每个已定义操作指定其在本次规程中须出现
**偶数次**或**奇数次**（逆元执行同样计入一次）。目标可导出时，系统进一步判定
是否存在满足整组奇偶要求的操作链；相容则返回**可逐步回放、逐操作计数可核对**的
规范因子链；仅奇偶要求不可满足时，展示**目标代表的奇偶向量、所需差额及恒等关系
独立基**。普通模式的结论与回放保持不变。

核心计算在 **Web Worker** 中按**端口标识排序**建立**确定性 Schreier–Sims 稳定子链**；
成员结论由各层**横截代表逐层剥离复算**，因子词再逐操作乘回独立校验；
奇偶相容性在该归约中构造的**恒等关系 GF(2) 奇偶空间**内线性求解并回构链路——
不枚举全部群元素、不穷举操作串、不使用随机搜索、不以有限深度回放代替。

## 置换记法

| 形式 | 示例 | 说明 |
| --- | --- | --- |
| 循环记号 | `(A B C)(D E)` | A→B→C→A，D↔E；未出现的端口为固定点 |
| 显式映射 | `A->B, B->C, C->A` | 接受 `->` `→` `=>` `:`；必须覆盖全部端口 |

每个操作必须是端口集合上的**双射**。重复操作名、缺失端口、非双射映射、非法目标等
**全部错误一次性返回**，且任何输入改动都**立即撤销旧结论**。

1. **代码测试**（`node --test`，43 项）——含一份可导出规程、一份不可导出目标、
   与全枚举 BFS 对 n≤5 全部目标的成员结论对照、A5=60 阶、S12=12! 阶、
   全量校验错误聚合、Worker 协议往返等；并对整组奇偶复核用独立的
   `(置换, GF(2)^m 奇偶向量)` 状态空间 BFS，对 n≤5 **全部目标 × 全部 2^m 要求向量**
   做相容性与规范链乘积/逐操作计数对照，覆盖可满足、不可满足（含平凡奇偶空间）、
   恒等目标、不可导出目标与 n=12 规模上限；

## 算法说明（确定性 Schreier–Sims）

- 基点顺序固定为端口标识排序后的 `[0,1,…,n-1]`；
- 每层 `i` 维护强生成元集 `S[i]`、基点轨道及**横截代表**（含对应的生成元词）；
- 初始生成元按操作名排序后逐条剥离；用 Schreier 生成元
  `β(x)·g·β(g(x))⁻¹` 反复闭合直至无新点、无新残差（确定性顺序、有限终止）；
- 目标剥离：逐层以横截代表之逆消去基点像；像点不在轨道内即给出
  **首个阻塞端口层 + 轨道证据**；全部基点消去为恒等则成员成立；
- 因子词 `target = t_{n-1}·…·t_0` 按可执行顺序展开，供逐步回放，并独立乘回复核。

### 整组奇偶复核：恒等关系的 GF(2) 奇偶空间

设生成元编号 `1..m`，因子词 `w` 的奇偶向量 `p(w) ∈ GF(2)^m` 为各操作
（含其逆元）出现次数模 2。令

```
K = { p(w) : w 求值为恒等 }
```

为**恒等词奇偶向量**构成的线性子空间。目标已有横截代表词 `w0`（奇偶 `v`）时，
“存在满足要求向量 `r` 的规程”当且仅当在被要求的坐标上 `v+r`（GF(2) 加法）
能被 `K` 补偿：即受限坐标线性方程组相容。

`K` 的基**直接在既有确定性归约中构造**，不枚举群元素或操作串：

1. 每个初始生成元词自第 0 层横截剥离到恒等，得恒等词 `a_k`；
2. 链闭包完成后，每层每个轨道点 `x` 与每个强生成元 `s` 的 Schreier 词
   `β(x)·s·β(s(x))⁻¹` 自下一层剥离到恒等，得恒等词 `b`。

由 Schreier–Sims / Reidemeister–Schreier 表示定理，这些恒等词在自由群中的
正规闭包恰为求值同态的核，故其奇偶向量张成整个 `K`；闭包终止时每个 Schreier
生成元都已剥离为恒等，样本可得且完备。所有候选词收录前均独立乘回验证为恒等，
再做 GF(2) 高斯消元得到按主元升序的 RREF 独立基。

相容时取解出的基组合，把对应恒等词（经自由词约简）拼到目标代表词之后：

```
规范因子链 = w0 ·（选中的恒等关系词）
```

其求值仍为目标，奇偶被精确修正到要求；终局再独立复算乘积并逐操作计数核对，
随后展开为可逐步回放、每步带逐操作累计计数的回放序列。不相容时返回目标代表
奇偶向量 `v`、差额 `v⊕r` 与独立关系基供核查。目标本身不可导出时，直接返回
原有的首个阻塞层，不进入奇偶判定。

## 并发与代次隔离

每次提交递增 `requestId`（代次）。计算未结束时改写规程——端口、操作、目标、
任一奇偶选择或切换审计模式——都会使代次前移并撤销旧结论；
旧 Worker 回包代次不匹配即被丢弃，**不会覆盖新输入或新结论**。
